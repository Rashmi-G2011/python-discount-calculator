# Discount Calculator

A Python-based discount calculator built using **Object-Oriented Programming (OOP)** concepts and multiple discount strategies.

## 📌 About the Project

This project calculates the best available price for a product by checking multiple discount strategies and selecting the lowest applicable price.

It was built as part of a Python/OOP workshop to practice object-oriented programming concepts in a practical project.

## 🚀 Features

* Product management using classes
* Percentage-based discounts
* Fixed-amount discounts
* Premium-user discounts
* Automatically selects the lowest applicable price
* Uses abstract classes and methods
* Uses type hints

## 🧠 Concepts Practiced

* Classes and Objects
* Encapsulation
* Inheritance
* Abstraction
* Polymorphism
* Abstract Base Classes (`ABC`)
* Abstract Methods
* Type Hints
* Strategy-based design

## 🛠️ Technologies Used

* **Python 3**
* Python `abc` module
